Core Skills & Architecture

Frontend: React, TypeScript, TanStack Query, MUI v6, Recharts

Main Backend: Java (Spring Boot) - 통합 비즈니스 로직, 보안(Security) 및 API Gateway

Data Engine: Python (FastAPI) - 한국투자증권 API 연동 및 AI 예측 엔진

DevOps & Cloud: GitHub Actions (CI/CD), Docker, Oracle Cloud (OCI), Supabase

[주요 구현 내용 및 사용 기술]
1. GitHub Actions 기반의 Full CI/CD 파이프라인 구축
CI/CD 자동화: 코드 Push 시 GitHub Actions를 통해 Spring Boot, FastAPI, React 각 모듈의 빌드 및 Docker 이미지 생성 자동화.

배포 프로세스: 빌드된 이미지를 Docker Hub에 푸시한 후, OCI(Oracle Cloud) 인스턴스에서 최신 컨테이너를 자동으로 Pull/Restart 하는 무중단 지향적 배포 환경 구축.

보안 관리: GitHub Secrets를 사용하여 API Key 및 DB 접속 정보를 엄격히 분리 관리하여 인프라 보안성 강화.

2. Spring Security & JWT 기반 보안 및 LMS 구축
인증/인가 시스템: Spring Security와 JWT(JSON Web Token)를 결합하여 Stateless한 인증 체계를 구축하고, 권한별 접근 제어(Role-based Access Control) 구현.

LMS(학습 관리 시스템) 단독 구현: 출석 관리, 학습 진도 추적, 과제 제출 등 복잡한 도메인 로직을 Spring Boot와 JPA를 활용해 단독 설계 및 구현.

외부 API 통합: Pokemon FreeAPI를 연동하여 외부 데이터를 수집하고 서비스화하는 모듈을 구축, 다각화된 데이터 소비(Data Consumption) 경험 확보.

3. 하이브리드 폴리글랏 및 금융 데이터 분석 엔진
언어별 최적화: 안정적인 권한 관리와 비즈니스 총괄은 Spring Boot가 담당하고, 금융 수치 계산 및 AI 예측 모듈은 FastAPI로 구축하여 도메인별 강점 극대화.

실전 주식 분석 파이프라인: 한국투자증권 API(KIS)와 FinanceDataReader를 활용해 실시간/과거 시세를 수집하고, Rate Limit 준수를 위한 인터벌 제어(time) 로직 적용.

AI 시계열 예측: Prophet 라이브러리와 Pandas, NumPy를 활용하여 미래 주가 추세 및 예측 신뢰 구간(Upper/Lower) 데이터 산출.

4. 데이터 기반 지능형 대시보드 및 상태 관리
인텔리전트 시각화: Recharts를 활용하여 실제 종가와 AI 예측 구간을 레이어링하고, RSI 과열/침체 구간 시각화로 투자 인사이트 제공.

성능 및 UX 최적화: TanStack Query 캐싱 전략을 도입하여 고비용 금융 API 호출 횟수를 최소화하고, MUI v6 기반의 반응형 UI를 통해 디바이스별 최적화된 경험 제공.
